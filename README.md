# Student Marks Prediction Using Machine Learning

## Project Overview
This project predicts student examination marks based on the number of hours they study. It demonstrates supervised machine learning using Python and Scikit-learn.

## Algorithms Used
1. Linear Regression
2. Decision Tree Regression

## Tools and Libraries
- Python
- Google Colab
- Pandas
- Matplotlib
- Scikit-learn

## Evaluation Metrics
- Mean Absolute Error (MAE)
- R² Score

Both models are evaluated on the same test dataset and compared using these metrics.

## Dataset
A small, manually created sample dataset containing study hours and marks. The data is illustrative and does not represent real students.

## How to Run
Open the notebook in Google Colab and execute the code cells in order.

## Conclusion
This project demonstrates how supervised machine learning models can learn from sample data, predict student marks, and be compared using evaluation metrics.
